# 发送通知标题输入框高度修复设计

## 背景

当前小程序发送通知页的标题输入框位于 `miniapp/pages/send/index.wxml`。该输入框直接复用全局 `.field-input` 样式，实际渲染时高度表现不正确，和页面其他表单控件的视觉节奏不一致。

## 目标

仅修复发送通知页标题输入框的高度问题，使其在微信小程序中呈现稳定、可读、与页面其余控件协调的单行输入框高度。

## 非目标

- 不修改全局 `.field-input` 样式
- 不调整正文输入框、绑定页输入框、自定义时长输入框
- 不改动业务逻辑、校验逻辑、交互文案

## 方案

采用页面级定向修复。

1. 在发送通知页标题输入框上增加一个专用类，例如 `send-title-input`
2. 在 `miniapp/pages/send/index.wxss` 中为该类显式声明单行输入框高度相关样式
3. 样式应至少包含明确的 `height`、`line-height` 和 `box-sizing`
4. 若仅设置高度仍导致内容垂直位置异常，可补充 `padding-top` 和 `padding-bottom` 的定向覆盖，但范围仅限该标题输入框

## 文件影响

- 修改 `miniapp/pages/send/index.wxml`
- 修改 `miniapp/pages/send/index.wxss`

## 验证

1. 在微信开发者工具打开发送通知页
2. 检查标题输入框高度是否恢复正常
3. 确认正文输入框、绑定页输入框、自定义时长输入框样式无变化

## 风险与控制

风险较低。此次改动只增加发送页局部类名并在页面级样式文件中覆盖，不影响复用全局 `.field-input` 的其他页面。
